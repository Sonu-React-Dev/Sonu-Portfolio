# Sonu Kumar — Premium Developer Portfolio

A production-oriented Next.js portfolio generated from Sonu Kumar's supplied resume and the supplied 2026 premium portfolio design specification.

## Stack

- Next.js + App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis smooth scrolling
- Lucide React
- Responsive / accessible-first structure

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Personal data

Resume-derived content is centralized in:

`data/portfolio.ts`

Update project URLs, contact email, portrait, exact social URLs, and any future metrics there before publishing.

## Important

The resume did not provide an email address, project demo URLs, GitHub repository URLs, or a portrait. Those are intentionally not fabricated. Replace the placeholder mail action and add real links before deployment.
